# dffy documentation

- [install.md](install.md): Homebrew, building from source, shell completions, the man page, supported platforms.
- [usage.md](usage.md): every subcommand and flag, revision and path syntax, stdin, comparing files and folders outside git, exit codes.
- [json.md](json.md): `--json` output for scripts and agents, the versioned schema of its header, file, hunk and line objects.
- [mcp.md](mcp.md): `dffy mcp`, the Model Context Protocol server for coding agents: registering it, its three tools, paging and truncation.
- [viewer.md](viewer.md): the full-screen viewer's layout, panels, search, selection and copy, phones.
- [keys.md](keys.md): every action with its default keys, and how to rebind them (generated).
- [config.md](config.md): the config file, every setting (generated), remembered settings.
- [themes.md](themes.md): built-in themes and writing your own.
- [git.md](git.md): dffy as git's pager, `git add -p` filter and `git difftool`, staging, repositories without commits.
- [watch.md](watch.md): watch mode, the `dffyd` broker, the Linux inotify limit, macOS.
- [plugins.md](plugins.md): experimental renderer plugins, the rendered view, the Markdown plugin, the protocol, writing your own; review plugins, `dffy-review-github` and the review protocol.
- [comments.md](comments.md): experimental review comments, the comments file's format, anchors and placement, and the operations of `dffy comments apply`.
- [troubleshooting.md](troubleshooting.md): `dffy doctor`, copying, the mouse, colors, a garbled terminal.
- [architecture.md](architecture.md): crates and modules, data flow, the engine, performance, testing and releases.
- [benchmarks.md](benchmarks.md): dffy timed against `delta`, `diff-so-fancy`, `difftastic`, `hunk` and `lumen` on the Linux kernel, the feature comparison with its sources, and how to rerun both.
